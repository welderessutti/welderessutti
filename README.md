### About me

I am a **Full-Stack Web Developer specialized in modern Angular and the Java/Spring ecosystem**, building maintainable web applications from responsive user interfaces to secure and scalable backend services.

My work covers the complete application flow:

- Modern Angular applications using TypeScript, standalone components, signals, RxJS, reactive forms, routing, guards, interceptors, and REST API integration
- Backend services using Java, Spring Boot, Spring Data, Spring Security, microservices, and messaging
- Reliable software delivery through automated testing, Docker, CI/CD, and cloud platforms

Before moving into software development, I spent **11+ years as a biomedical scientist** in clinical laboratories and regulated environments. This background gives me practical experience with healthcare workflows, data quality, traceability, and system reliability—especially valuable when building solutions for HealthTech and other data-sensitive domains.
